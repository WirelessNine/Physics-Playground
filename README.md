  <h1>Physics Playground</h1>
  <p>A small game by WirelessNine</p>
</div>

Physics playground is a very simple and primitive physics sandbox and simulation game built using Godot Engine and Rapier2D physics.

<img src="assets/repo/ss1.png" width="200">

My main source of inspiration for this project was People Playground, a more mature (and gorey) physics sandbox, and I wanted to see if I could make a game similar to it, and it was difficult, and not very fun. Turns out physics are a lot more complex than I thought!
